# Problem Statement
Students often struggle to manually track whether they meet the specific academic and technical eligibility criteria set by different companies visiting campus for recruitment. 

# Scope
This project checks class 10 marks, class 12 marks, CGPA, active backlogs of final year b.tech cse student to check eligibility against company-specific recruitment rules.

# Target Users
- Final year b.teah cse students checking company eligibility.
- Placement Coordinators / Admin managing campus recruitment.

# High-Level Features
- Student Profile Input (class 10 marks, class 12 marks, CGPA, Backlogs).
- Company Criteria Matching (Filter based on cutoffs).
- Instant Eligibility Result.
