# placement-interview-eligibility-checker

## Overview
A Python-based software tool designed to help students quickly verify if they meet the eligibility criteria for upcoming campus placement drives based on company requirements.

## Features
- Input student academic details (Class 10%, Class 12%, Semester, Active Backlogs, and CGPA).
- Automated eligibility verification logic based on standard cutoffs.
- Instant validation for input errors (e.g., preventing invalid percentage or backlog entries).
- Clear pass/fail eligibility result output.

## Eligibility Criteria Used
- Class 10th: Minimum 60%
- Class 12th: Minimum 60%
- Active Backlogs: 0
- CGPA: Minimum 8.5
- Eligible Semesters: 7th or 8th semester (Final Year)

## How to Run
1. Download or clone this repository.
2. Open terminal/VS Code in the project folder.
3. Run the Python script:
   `python main.py`
